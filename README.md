# Tanmay Pawar · portfolio

Next.js 16 (App Router) + Tailwind v4. Light/dark theme, markdown blog, contact form via Web3Forms. No database, no server code to run.

## Run locally

```bash
npm install
cp .env.example .env.local   # then fill in the two values below
npm run dev                  # http://localhost:3000
```

## Environment variables

| Name | What it is |
| --- | --- |
| `NEXT_PUBLIC_WEB3FORMS_KEY` | Free access key from https://web3forms.com (enter tanmaymsp@gmail.com, the key arrives by email). Messages from the form go to that inbox. |
| `NEXT_PUBLIC_SITE_URL` | Your live URL, e.g. `https://tanmay-pawar.vercel.app`. Used for sitemap and link previews. |

Without the Web3Forms key the form shows "isn't configured yet" and nothing is sent.

## Edit your content

Everything personal is in `src/data/`:

- `site.ts` name, email, links, tagline, About paragraphs
- `experience.ts`, `education.ts`, `projects.ts`, `stack.ts`
- Add a project link by adding `links: [{ label: "GitHub ↗", href: "...", external: true }]` to its entry in `projects.ts`.
- Résumé: put your PDF at `public/Tanmay_Pawar_Resume.pdf` (the buttons already point there).

## Blog

Each post is a markdown file in `content/blog/`:

```md
---
title: "My post"
date: "2026-12-01"
summary: "One or two sentences shown in lists and the featured tile."
topic: "On-device LLM"        # small label on the featured tile
tags: ["llama.cpp", "Android"]
featured: true                # shows on the home page as a tile
draft: false                  # true hides it in production
---
Markdown body here.
```

- `/blog` lists every post, `/blog/<file-name>` is the post page.
- Posts with `featured: true` appear as stacked tiles on the home page (one tile now, more stack up as you add them).
- `content/blog/running-a-3b-llm-in-700mb.md` is a placeholder outline. Replace the `[...]` parts with your write-up.

## Deploy (Vercel, free)

1. Create a GitHub repo (e.g. `Tanmay-jam/portfolio`) and push this folder.
2. On vercel.com choose **Add New → Project**, import the repo, keep the defaults.
3. Add the two environment variables above, then deploy. Every push to `main` redeploys.

## Notes

- Brand logos are inlined from `src/lib/brand-icons.ts` (generated by `scripts/gen-icons.mjs` from simple-icons).
- Accent colour: `--accent` at the top of `src/app/globals.css`.
- This repo uses a recent Next.js release with Cache Components on; see the docs in `node_modules/next/dist/docs/` before changing data fetching.
